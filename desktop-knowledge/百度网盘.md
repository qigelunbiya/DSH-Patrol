# 百度网盘 Windows 操作指南

## 原则

百度网盘不同版本可能大量使用自绘 UI。优先尝试 UI Automation；UIA 信息不足时使用 OCR 与当前截图辅助，不持久化历史绝对坐标。

## 搜索文件

1. 激活百度网盘。
2. 优先尝试 Ctrl+F；若无效，使用 desktop_snapshot 查找“搜索”输入框。
3. 输入文件名。
4. 等待结果加载。
5. UIA 无法读取结果时使用 desktop_ocr。

## 打开 / 下载

- 优先按文件名语义定位目标。
- 同名文件不唯一时需要结合目录、大小、日期等额外证据。
- 下载后的文件操作可结合 desktop_open_path。
